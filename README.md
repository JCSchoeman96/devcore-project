# DevCore Project

This repository is the canonical source for the shared `devcore-project` workstation tool.

Ticketing, EventSales, and other application repositories consume DevCore through project-level `.devcore/` declarations. They do not own the executable, schema, renderer, or installer.

The initial repository seed records ownership only. Historical v1.0.0 artifacts remain unverified until their provenance and code delta are documented in the canonicalization review.
