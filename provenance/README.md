# Legacy provenance

`legacy-v1.0.0/` holds two historical artifacts recovered from the workstation. The user, JCSchoeman96, created and owns all DevCore materials. No historical Git repository, source commit, or tag was recovered for these artifacts, and neither is declared the original canonical Git source. The missing Git history does not change the established ownership. They are retained as evidence and must not be used as the canonical source without the baseline decision in [provenance documentation](../docs/provenance.md).

The ZIP is stored unchanged. The installed script copy preserves its exact bytes; Git does not preserve its original mode metadata. `legacy-v1.0.0/SHA256SUMS` records the ZIP and installed-script hashes. CI also verifies the archive's own checksum manifest and the bundled script hash.
